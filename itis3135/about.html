This course seeks to provide students relevant experience in front-end web application development by building multiple websites using a variety of tools and techniques.

The Tools This Course Uses

  1. VS Code
  2. Emmet within VS Code
  3. SFTP via Filezilla
  4. Git via GitHub Desktop and GitHub.com
  5. Various Browser tools
  6. The Accumulus Validator

The Sites Students Will Build

  1. A personal home portfolio
  2. This course site
  3. A design firm site - representing a fictitious/aspirational design/consulting firm for the student and named after them
  4. A Crappy page - intended to do all the bad things, so as to avoid them anywhere else
  5. A whimsical product company
  6. A student/colleague/peer management tool
  7. A client project website
